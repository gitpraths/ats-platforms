3. Detailed Feature Breakdown
🔑 Admin Role Super User
  • Full access to all 11 system modules and reports.
  • Exclusive authority to delete records (Candidates, Vacancies, Placements, Applications).
  • Ability to dynamically create users and change staff access levels inside User Management.
👤 Staff Role Recruiters & Consultants
  • Full access to Dashboard, Vacancies, Candidates, Placements, Employers, Providers, and Training.
  • Restricted from accessing Invoice/Xero generate & view features (returns 403 Forbidden).
  • Restricted from deleting records (Delete buttons hidden in UI; API routes guarded).
📋 Training Admin Role Training Specialist
  • Access limited strictly to Candidates (view-only) and Training Program (full access).
  • Full candidate search capability enabled (can search by name, phone, email, status).
  • Candidate phone number and email address are visible. Create/Edit/Delete buttons are hidden.
  • All other modules (Dashboard, Vacancies, Important Updates, Placements, Employers, Providers, Invoices) are hidden from navigation bar.
🌐 Vacancy Website Synchronization Inquiry Feature Clarification
  • Database-Driven Website (Supported): Automated 2-way vacancy publishing is fully supported if your website is database-driven (e.g. WordPress, Webflow, dynamic CMS, or custom API). An API Webhook can be connected so clicking "Publish Vacancy" in WVA CRM automatically posts the job live onto your website.
  • Static Website (Not Possible Directly): If your website is a static HTML website (without a database backend), automated live vacancy syncing is not possible directly. Staff can copy/paste the exported vacancy specifications or link to the job board URL.
  • Current CRM Capability: Vacancies created in WVA CRM store job board links, manage applicant pipeline flow, and export complete vacancy specifications.
