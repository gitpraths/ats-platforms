1. Safety Guarantee & Account Creation

Step 1 of 4
🛡️ Zero Downtime Guarantee:

Your main website (https://workvision.com.au), WordPress files, database, and company emails on Cyberinfo remain 100% intact and unaffected. Only the DNS signboard is upgraded to Cloudflare so that subdomains activate in seconds.

1
Create Free Cloudflare Account
  • Go to https://dash.cloudflare.com/sign-up in your browser.
  • Enter your email address and choose a password.
  • Click Create Account.
2
Add Your Domain
  • On the Cloudflare dashboard, click the blue button: Add a site (or Add a domain).
  • Type exactly: workvision.com.au and click Continue.
  • Scroll down to the pricing options and select the Free ($0 / month) plan.
  • Click Continue.

2. Verify Records & Add Subdomain

Step 2 of 4

Cloudflare will automatically scan all existing DNS records from Cyberinfo. Review the table to make sure your main site remains intact, and add the new CRM record.

3
Verify Main Website & Add CRM Subdomain

Ensure your main website records are present, then click Add Record to add the CRM:

Record Type Name Target / IP Address Proxy Status
A (Main Site) @ (or workvision.com.au) 203.28.49.193 Proxied (Orange Cloud)
A / CNAME www workvision.com.au Proxied (Orange Cloud)
CNAME (New CRM) crm gna5aacw.up.railway.app ⚠️ DNS Only (Grey Cloud)
⚠️ Critical Requirement for CRM Subdomain:

When adding the crm CNAME record, click on the orange cloud icon so it changes to DNS Only (Grey Cloud). This allows Railway to automatically issue and manage the SSL certificate.

  • Click Continue once all records are confirmed.

3. Update Nameservers in Cyberinfo

Step 3 & 4 of 4
4
Get Nameservers from Cloudflare

Cloudflare will now display two unique nameservers on your screen (for example: alex.ns.cloudflare.com and olga.ns.cloudflare.com). Copy both.

5
Replace Nameservers in Cyberinfo
  • Log in to Cyberinfo: https://www.cyberinfo.com.au/members.
  • Go to Domains > Details (workvision.com.au).
  • At the top, locate the Name Servers section (showing ns3/ns4.secureparkme.com).
  • Click the menu icon (≡) on the right of the Name Servers bar.
  • Replace:
    • Name Server 1: Enter 1st Cloudflare nameserver
    • Name Server 2: Enter 2nd Cloudflare nameserver
  • Click Update / Save.
🎉 Congratulations — Activation Complete!

Return to Cloudflare and click "Done, check nameservers". Within 5 to 10 minutes:
• Main site continues running: https://workvision.com.au
• CRM portal is live with SSL: https://crm.workvision.com.au
