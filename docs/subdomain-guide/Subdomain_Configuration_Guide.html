1. Overview & Architecture

Step 1 of 3

This guide explains how to connect your dedicated CRM portal to https://crm.workvision.com.au without affecting your main public website (https://workvision.com.au).

💡
Your Main Website Remains 100% Intact

Your root website at workvision.com.au continues pointing to IP 27.124.125.173 as currently configured. We are only adding an independent subdomain record (CNAME) specifically for the CRM.

1
Add Custom Domain in Railway Dashboard
  • Log in to your Railway.com console.
  • Open your ATS Project and click on the primary frontend service: comfortable-mindfulness-production.
  • Go to the Settings tab along the top navigation bar.
  • Scroll down to the Public Networking (or Networking) section.
  • Click the + Custom Domain button.
  • Type exactly: crm.workvision.com.au and click Add.
Important:

Railway will immediately provide you with a CNAME target (either comfortable-mindfulness-production.up.railway.app or a custom routing URL). You will enter this target in Cyberinfo in the next step.

2. Adding DNS Record in Cyberinfo

Step 2 of 3

Log in to your domain registrar account at https://www.cyberinfo.com.au/members/ and navigate to Domains > Details (workvision.com.au).

Cyberinfo Control Panel — Domain Details workvision.com.au
Action Required: In the DNS Settings card (highlighted above with the blue bar), click the menu button (≡) on the right side to add the new CNAME record.
2
Enter the CNAME Record Values
  • Click Add Record (or select New Record from the DNS Settings menu).
  • Fill in the fields exactly as defined in the table below:
Field What to Select / Enter Notes
Record Type CNAME Canonical Name alias record
Host / Subdomain crm Creates crm.workvision.com.au
Points to / Value comfortable-mindfulness-production.up.railway.app Your Railway public project URL
TTL 3600 (or 1 Hour / Automatic) Default time-to-live
  • Click Save Changes / Add Record to submit.

3. Verification & Direct Login Access

Step 3 of 3
3
SSL Certificate & Activation
  • DNS propagation generally takes between 5 and 20 minutes worldwide.
  • Return to your Railway Project > Settings > Networking.
  • Railway automatically provisions a free SSL Certificate (HTTPS) via Let's Encrypt once it detects the CNAME.
  • The domain status will turn green with a Active badge.
🔒
Automatic Direct Redirection to Login

The latest code update has already been applied: when anyone opens https://crm.workvision.com.au (or clicks the link directly), it will automatically redirect straight to the Login Page!
