How to Get Started

1

Open the Excel file

Double-click any of the attached .xlsx files to open it in Microsoft Excel or Google Sheets.

2

Read the Instructions sheet first

Each file has two sheets — 📋 Instructions and DATA. Start by reading the Instructions sheet to understand what each column means.

3

Fill in the DATA sheet

Click on the DATA tab. Add one row per record (one candidate per row, one employer per row, etc.). You can delete the sample rows that are already there.

4

Do not change the column headers

The orange and grey header row at the top must stay exactly as it is. Do not rename, delete, or move any columns.

5

Send the completed files back

Once done, save the file and send it back to us via WhatsApp or email. We will handle the rest.

📏

Important Rules to Follow

🚫

Please read these carefully before filling in any data

Mistakes here can cause records to be rejected or imported incorrectly.

  • 🟠 Orange column headers are REQUIRED — you must fill these in for every row. Grey headers are optional.
  • Do NOT rename, delete, or move columns — even if you don't use a column, leave it blank, do not remove it.
  • One record per row — each row = one candidate, one employer, one vacancy, etc.
  • Dates must be in YYYY-MM-DD format — for example 2026-01-15 not 15/01/2026 or Jan 15 2026.
  • Use the dropdowns provided — for fields like Work Status, Employment Type, Wage Subsidy etc., click the cell and pick from the dropdown list. Do not type free text in these cells.
  • Yes / No fields — only enter yes or no (lowercase). Do not use Y/N or True/False.
  • Numbers only in number fields — for Benchmark Hours enter 38 not "38 hours". For Pay Rate enter 28.50 not "$28.50".
  • Email addresses must be unique — each candidate must have a different email. If a candidate has no email, leave the cell blank.
  • Provider name must match exactly — in the Candidates template, the provider_name must be spelled exactly as the training provider organisation is listed in your system.
  • Do not add extra columns — only fill in the columns that are already in the template.
  • Delete the sample rows — the first 3 rows in the DATA sheet are examples. Please delete them before submitting.

Tip — Format the date column in Excel

Select the date column → Right click → Format Cells → Choose Text — then type dates in YYYY-MM-DD format. This stops Excel from converting them automatically.

How to Submit Your Completed Files

🧪
Remember — First send only 5 records!

Fill in just 5 rows first. Wait for our confirmation before entering the rest of your data.

1

Enter only 5 records first (test run)

Open the DATA sheet and fill in 5 rows only as a test. Delete the existing sample rows. Do not enter all your records yet.

2

Save the file in Excel format (.xlsx)

File → Save As → make sure the format is Excel Workbook (.xlsx). Do not save as CSV or PDF.

3

Send the 5-record file back via WhatsApp

Reply to this WhatsApp message with the completed file attached. We will import the 5 records and check everything is correct in the system.

4

Wait for our confirmation ✅

We will message you back confirming the 5 records are imported correctly. Please wait for this message before proceeding.

5

Fill in all your remaining records

Once confirmed, go back to the Excel file and add all your remaining records below the first 5. Save and send the complete file back to us for full import.
